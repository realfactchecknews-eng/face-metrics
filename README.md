# Face Metrics — геометрический анализ пропорций лица

Статический веб-инструмент для анализа геометрических пропорций и
симметрии лица с рекомендациями по стрижке и стилю. **Не является
оценкой привлекательности** — измеряет только числовые соотношения
(пропорции третей лица, ширину зон, симметрию), как это делает стилист
с сантиметровой лентой.

## Как это работает

1. Пользователь загружает фото (drag&drop или выбор файла).
2. [MediaPipe Face Mesh](https://github.com/google/mediapipe) находит 468
   ключевых точек лица — полностью в браузере, без отправки на сервер.
3. `metrics.js` вычисляет геометрические соотношения: пропорции третей
   лица, ширину лба/скул/челюсти, отношение ширины к высоте, симметрию
   относительно вертикальной оси.
4. `recommendations.js` сопоставляет полученную форму лица со
   справочными рекомендациями по стрижкам (rule-based, без ML).

## Приватность

- Вся обработка происходит **локально в браузере пользователя** (on-device).
- Изображение не отправляется ни на один сервер и не сохраняется —
  ни в localStorage, ни в cookies, ни где-либо ещё.
- Единственный сетевой запрос — загрузка самой модели MediaPipe с CDN
  при первом открытии страницы (кэшируется браузером на будущее).

## Ограничения и важные оговорки

- Это **не диагностика** и не медицинский инструмент.
- Оценка формы лица — упрощённая эвристика на геометрических
  соотношениях, а не профессиональная консультация стилиста.
- Точность landmarks зависит от качества фото: освещения, угла камеры,
  разрешения.
- Небольшая асимметрия лица — это физиологическая норма практически у
  всех людей, а не недостаток, который нужно исправлять.

## Стек

Чистые HTML/CSS/JavaScript, без сборки и без зависимостей кроме
MediaPipe (подключается через CDN). Можно открыть `index.html` напрямую
или задеплоить как статический сайт.

## Локальный запуск

Открыть `index.html` в браузере. Для корректной работы `fetch` к CDN
рекомендуется открывать через локальный сервер, а не `file://`:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой на GitHub Pages

1. Запушить репозиторий на GitHub.
2. В настройках репозитория: **Settings → Pages → Source → Deploy from a branch**,
   выбрать branch `main` и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу
   `https://<username>.github.io/<repo-name>/`.

## Структура файлов

```
.
├── index.html          — разметка страницы
├── style.css            — стили
├── metrics.js            — вычисление геометрических метрик по landmarks
├── recommendations.js    — справочные рекомендации по стрижкам/стилю
├── app.js                — связка UI + MediaPipe + метрики
└── README.md
```
