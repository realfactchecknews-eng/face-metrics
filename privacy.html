Политика конфиденциальности

Редакция от 19.06.2026

Настоящая Политика описывает, какие данные обрабатывает веб-сервис FaceRate (далее — «Сервис», facerate.ru) и как они используются. Используя Сервис, вы соглашаетесь с условиями настоящей Политики.

Изображение лица может относиться к биометрическим персональным данным. Обработка выполняется только с вашего согласия, которое вы даёте, загружая фотографию и подтверждая Пользовательское соглашение. Вы можете в любой момент прекратить использование Сервиса.

1. Какие данные обрабатываются

  • Загруженное изображение — фотография лица, которую вы добавляете для анализа. Используется исключительно для разовой обработки запроса.
  • Технические данные — IP-адрес. Используется автоматически для защиты Сервиса от злоупотреблений (ограничение числа запросов). Не используется для идентификации личности.
  • Локальные данные браузера (localStorage) — числовой результат (балл), история баллов, факт принятия соглашения, настройки звука. Хранятся только на вашем устройстве и не передаются на сервер.

2. Цели и правовое основание

  • Цель — формирование развлекательной эстетической оценки по загруженному изображению и отображение результата.
  • Правовое основание обработки изображения — ваше согласие.

3. Как происходит обработка изображения

  • Геометрические измерения лица выполняются локально в вашем браузере.
  • Для текстовой оценки изображение передаётся через защищённый прокси стороннему провайдеру ИИ-модели. Это необходимо для работы функции оценки.
  • Сервис не ведёт постоянного хранилища загруженных фотографий: изображение используется для одного запроса и не сохраняется Сервисом после получения ответа.

4. Передача третьим лицам

Для работы Сервиса данные обрабатываются с участием:

  • Провайдера ИИ-модели (через сервис-маршрутизатор OpenRouter) — для генерации текста оценки по изображению;
  • Инфраструктурных провайдеров (Cloudflare — прокси/защита, GitHub Pages — хостинг статических файлов).

Указанные провайдеры могут обрабатывать данные на серверах за пределами Российской Федерации. Сервис не передаёт данные в иных целях и не продаёт их.

5. Сроки хранения

Загруженное изображение не сохраняется Сервисом после обработки запроса. Локальные данные (балл, история) хранятся в вашем браузере до тех пор, пока вы их не удалите (очистка данных сайта / истории браузера).

6. Ваши права

  • Отозвать согласие и прекратить использование в любой момент.
  • Удалить локальные данные, очистив данные сайта в браузере.
  • Не загружать изображение, если вы не согласны с обработкой.

7. Cookie и аналогичные технологии

Сервис не использует рекламные cookie. Применяется только localStorage для хранения настроек и результатов на вашем устройстве.

8. Изменения

Политика может обновляться. Актуальная редакция всегда доступна на этой странице.

Документ является типовым шаблоном информационного характера и не заменяет юридическую консультацию. Для полного соответствия применимому законодательству о персональных данных рекомендуется проверка квалифицированным юристом.
