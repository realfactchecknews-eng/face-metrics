Политика конфиденциальности

Редакция от 08.07.2026

Настоящая Политика описывает, какие данные обрабатывает веб-сервис FaceRate и связанные с ним Telegram-боты (далее вместе — «Сервис», facerate.ru) и как они используются. Используя Сервис, вы соглашаетесь с условиями настоящей Политики.

Изображение лица может относиться к биометрическим персональным данным. Обработка выполняется только с вашего согласия, которое вы даёте, загружая фотографию и подтверждая Пользовательское соглашение. Вы можете в любой момент прекратить использование Сервиса.

1. Какие данные обрабатываются

  • Загруженное изображение — фотография лица, которую вы добавляете для анализа. Используется исключительно для разовой обработки запроса.
  • Данные Telegram-аккаунта — идентификатор аккаунта, имя и username (если указаны). Используются для входа, учёта квоты и связи покупки с аккаунтом. Мы не запрашиваем номер телефона.
  • Данные об оплате — какой тариф куплен, сумма, способ оплаты (Telegram Stars / криптовалюта / банковская карта) и время покупки. Реквизиты карты или криптокошелька Сервису не передаются и не хранятся — их обрабатывает исключительно платёжный провайдер.
  • Сообщения в поддержку — текст обращения в бот поддержки при эскалации на оператора; хранится временно для ответа на обращение.
  • Технические данные — IP-адрес. Используется автоматически для защиты Сервиса от злоупотреблений (ограничение числа запросов). Не используется для идентификации личности.
  • Локальные данные браузера (localStorage) — числовой результат (балл), история баллов, факт принятия соглашения, настройки звука. Хранятся только на вашем устройстве и не передаются на сервер.

2. Цели и правовое основание

  • Цель — формирование развлекательной эстетической оценки по загруженному изображению, учёт купленного доступа и его выдача, ответы на обращения в поддержку.
  • Правовое основание обработки изображения — ваше согласие. Правовое основание обработки данных об оплате — исполнение договора (предоставление оплаченного доступа).

3. Как происходит обработка изображения

  • Геометрические измерения лица выполняются локально в вашем браузере.
  • Для текстовой оценки изображение передаётся через защищённый прокси стороннему провайдеру ИИ-модели. Это необходимо для работы функции оценки.
  • Сервис не ведёт постоянного хранилища загруженных фотографий: изображение используется для одного запроса и не сохраняется Сервисом после получения ответа.

4. Передача третьим лицам

Для работы Сервиса данные обрабатываются с участием:

  • Провайдера ИИ-модели (через сервис-маршрутизатор OpenRouter) — для генерации текста оценки по изображению;
  • Telegram (Bot API) — для входа, уведомлений, работы ботов и приёма оплаты Stars;
  • Платёжных провайдеров — сервиса приёма криптовалютных платежей и (при доступности способа оплаты картой) провайдера эквайринга — для обработки платежей банковской картой/криптовалютой. Данные карты/кошелька обрабатываются исключительно этими провайдерами;
  • Инфраструктурных провайдеров (Cloudflare — прокси, защита и хранение данных аккаунта/квот, GitHub Pages — хостинг статических файлов).

Указанные провайдеры могут обрабатывать данные на серверах за пределами Российской Федерации. Сервис не передаёт данные в иных целях и не продаёт их.

5. Сроки хранения

  • Загруженное изображение не сохраняется Сервисом после обработки запроса.
  • Данные аккаунта (идентификатор Telegram, баланс кредитов/безлимита) хранятся, пока аккаунт используется.
  • Записи об оплатах хранятся в течение срока, необходимого для учёта, рассмотрения споров и соблюдения применимого законодательства.
  • Сообщения в поддержку хранятся временно, как правило не дольше нескольких месяцев, и могут быть удалены по запросу.
  • Локальные данные (балл, история) хранятся в вашем браузере до тех пор, пока вы их не удалите (очистка данных сайта / истории браузера).

6. Ваши права

  • Отозвать согласие и прекратить использование в любой момент.
  • Запросить удаление данных вашего аккаунта, включая историю обращений в поддержку, написав в @FaceRateSupport_bot (данные об оплатах, необходимые для учёта, могут храниться дольше в силу применимого законодательства).
  • Удалить локальные данные, очистив данные сайта в браузере.
  • Не загружать изображение, если вы не согласны с обработкой.

7. Cookie и аналогичные технологии

Сервис не использует рекламные cookie. Применяется только localStorage для хранения настроек и результатов на вашем устройстве.

8. Изменения

Политика может обновляться. Актуальная редакция всегда доступна на этой странице.
